# DailyHub gộp tin Việt Nam, AI, Devs, GitHub và Prompt Spider

1. Mở FreeLLMAPI Desktop để bật router AI cục bộ (mặc định `127.0.0.1:31415`).
2. Chạy `Run-FreeLLMAPI-Spider.bat`.
3. Mở `http://127.0.0.1:8766/index.html`.
4. DailyHub kết hợp RSS tin tức, phân tích AI, GitHub, Thư viện AI và Prompt Spider.

Tin được AI tóm tắt, phân loại, tìm theo ý nghĩa; Thư viện AI có tìm kiếm ngữ nghĩa, xếp hạng tài nguyên và hỏi đáp dựa trên kết quả tìm thấy. AI tự động có thể tuyển chọn tài nguyên sau mỗi lần đồng bộ theo lịch khi được bật trong Nguồn & cài đặt.

API key được giữ cục bộ và mã hóa bằng Windows DPAPI. Không đưa secret vào repo. Xem hướng dẫn đầy đủ trong README.
